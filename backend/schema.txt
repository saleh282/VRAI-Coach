VRAI-Coach Database Schema v1
=============================

Purpose
-------
The database stores interview users, interview sessions, and AI/Human
evaluations. A human evaluation is internal ground truth used to validate the
AI model. It is not currently part of the score shown to the user.

Relationships
-------------

User 1 -> many Sessions
Session 1 -> many Evaluations
User (rater) 1 -> many Human Evaluations

users
-----
_id            ObjectId
name           String, required, trimmed
email          String, required, unique, lowercase, trimmed
passwordHash   String, required
role           String: user | rater | admin
createdAt      Date, automatic
updatedAt      Date, automatic

sessions
--------
_id            ObjectId
userId         ObjectId -> users, required
sessionType    String: interview
category       String: tech | soft_skills
difficulty     String: easy | medium | hard
status         String: pending | in_progress | completed | cancelled | failed
transcriptRef  String, optional protected-storage reference
audioRef       String, optional protected-storage reference
videoRef       String, optional protected-storage reference
startedAt      Date, optional
completedAt    Date, optional
createdAt      Date, automatic
updatedAt      Date, automatic

evaluations
-----------
_id             ObjectId
sessionId       ObjectId -> sessions, required
evaluatorType   String: AI | HUMAN
raterId         ObjectId -> users, required for HUMAN
modelVersion    String, required for AI
rubricVersion   String, required, default 1.0.0
status          String: DRAFT | SUBMITTED
scores          Object with communication, clarity, confidence, contentQuality
overallScore    Number 0-100, calculated by the backend
feedback        String, optional
evidenceNote    String, required for submitted HUMAN evaluations
submittedAt     Date, set automatically on submission
createdAt       Date, automatic
updatedAt       Date, automatic

Scoring rubric v1
-----------------
communication   30%
clarity         25%
confidence      20%
contentQuality  25%

Every score is between 0 and 100. Draft evaluations may be incomplete. A
submitted evaluation must contain every rubric score. Human and AI evaluations
can only be compared when rubricVersion is the same.

Indexes and constraints
-----------------------
- users.email is unique.
- users.role is indexed.
- sessions are indexed by userId/createdAt and status.
- evaluations are indexed by sessionId.
- One submitted AI evaluation is allowed per session/model/rubric version.
- One submitted Human evaluation is allowed per session/rubric version in v1.
